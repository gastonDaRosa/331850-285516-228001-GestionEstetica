# 331850-285516-228001-GestionEstetica
Software orientado a mejorar la gestión de clientes, servicios, reservas y pagos de Estética y Salud Leniza Acuña, emprendimiento dedicado a la prestación de tratamientos estéticos, terapéuticos y de bienestar. La solución contempla una aplicación web responsiva y la integración con WhatsApp como canal alternativo de interacción para los clientes.
